# Разработка chessBoard

Эти инструкции действуют во всём репозитории. При работе над задачей открой соответствующие разделы [правил для ИИ-ассистентов](_docs/ai/README.md).

Для размещения кода используй [архитектуру проекта](ARCHITECTURE.md). При реализации функции сверяй результат с критериями её этапа в [плане разработки](ROADMAP.md). После изменения клиента выполни `npm test` и `npm run build`.

Подробные сценарии и критерии приёмки крупных функций веди в [каталоге функций](docs/features/README.md). Обновляй описание вместе с изменением поведения.

## Работа в Codex

Веди шаг по [общему порядку работы](_docs/ai/workflow.md). Для небольших задач выполни реализацию и проверку в основном чате.

При делегировании передай [исполнителю](.codex/agents/builder.toml) цель игрока, границы правки и проверку. Распределяй параллельно только независимые изменения с разными файлами для записи. Для независимого ревью передай [проверяющему](.codex/agents/reviewer.toml) исходное задание, состав изменений и результаты тестов.

Приёмку веди в основном чате. Сверь итоговый diff с заданием, воспроизведи ключевой сценарий на общей версии и исправь подтверждённые расхождения. В запуске по ROADMAP.md зафиксируй принятый результат и его проверки, сделай локальный коммит шага и переходи к следующему пункту согласно заданию на запуск.
