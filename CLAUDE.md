## Работа в Claude Code

Для самостоятельного шага используй [общий порядок работы](_docs/ai/workflow.md). Если задача делегируется, передай [builder](.claude/agents/builder.md) цель, границы правки и проверку. Параллельные задания должны иметь независимые результаты и разные файлы для записи.

Перед приёмкой проверь итоговый diff и повтори проверку критерия на собранном результате. Для независимого чтения изменений передай [reviewer](.claude/agents/reviewer.md) исходное задание, diff и результаты проверок. Обнаруженное расхождение верни исполнителю со сценарием воспроизведения. Ведение ROADMAP.md и коммит согласованного шага остаются у ведущего.
