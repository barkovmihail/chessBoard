# Турнирная арена

Раздел «Турниры» показывает арены в порядке создания. Любой читатель может открыть арену и увидеть её участников. Для создания арены, записи и отмены регистрации используется аккаунт игрока. Организатор при создании автоматически входит в состав участников. Адрес арены можно отправить другому игроку.

Первый формат — нерейтинговый блиц 5+3. Состав обновляется автоматически и восстанавливается из SQLite после перезапуска. Повторная регистрация одного аккаунта занимает одно место.

## Партии и результаты

При двух зарегистрированных участниках организатор может начать арену на 30 минут. Состав фиксируется при старте. «Готов к партии» ставит игрока в очередь. До подбора можно отменить ожидание. Первые два готовых участника получают ссылку на одну нерейтинговую партию 5+3. При повторной встрече цвета меняются. Ходы, часы, сдача и ничья обрабатываются обычным сервисом партий. После результата «Вернуться на арену» открывает таблицу и позволяет снова заявить готовность.

За победу игрок получает два очка, за ничью — одно, за поражение — ноль. При равенстве очков участники показаны по имени. Сервер вычисляет очки по результатам связанных с ареной партий. Повторная доставка результата или обновление страницы не меняет сумму.

Через 30 минут или по кнопке организатора «Завершить арену» подбор прекращается. Начатые партии можно доиграть. После их завершения участники и зрители видят итоговую таблицу по прежнему адресу.

Регистрация, подбор пары и итоговая таблица используют язык меню профиля. Название арены и имена участников сохраняют авторское написание.
