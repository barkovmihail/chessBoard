# Турнирная арена

Раздел «Турниры» показывает арены в порядке создания. Любой читатель может открыть арену и увидеть её участников. Для создания арены, записи и отмены регистрации используется аккаунт игрока. Организатор при создании автоматически входит в состав участников. Адрес арены можно отправить другому игроку.

Первый формат — нерейтинговый блиц 5+3. Состав обновляется автоматически и восстанавливается из SQLite после перезапуска. Повторная регистрация одного аккаунта занимает одно место.

Следующие шаги — старт арены организатором, подбор свободных участников в партии, подсчёт очков и итоговая таблица.
