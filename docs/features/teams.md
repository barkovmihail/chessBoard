# Команды и приглашения

Раздел «Команды» открывается из профиля. Игрок с аккаунтом создаёт команду и приглашает знакомого по имени аккаунта. Создатель видит состав и ожидающие приглашения. Адресат может принять или отклонить приглашение. После принятия состав доступен обоим игрокам, в том числе после входа на другом устройстве. Список обновляется автоматически при открытом разделе.

В SQLite одному игроку соответствует одно место в команде. Повтор приглашения не создаёт вторую запись и сохраняет уже принятое членство. Посторонний аккаунт не видит команду и не может принять приглашение по чужому идентификатору.

На приглашении видно имя отправителя. «Отключить приглашения» снимает все ожидающие приглашения этого отправителя и запрещает новые приглашения в его команды. Существующее членство сохраняется. Внизу раздела игрок видит свой список «Приглашения отключены» и может снова разрешить приглашения. После разблокировки отправитель может пригласить игрока заново.

## Публичный чат

Раздел «Чат» показывает последние 50 видимых сообщений. Гость может читать, аккаунт — писать сообщения до 500 символов, отключать ленту и скрывать отдельных авторов. Настройки относятся к аккаунту и сохраняются в SQLite. Блокировка приглашений в команды настраивается отдельно.

Кнопка «Пожаловаться» передаёт сообщение в очередь модерации. Одна жалоба от игрока на сообщение учитывается один раз. Модератор может скрыть сообщение для всех или отклонить жалобы. Решение и идентификатор модератора сохраняются вместе. Следующее обновление ленты применяет решение к открытым вкладкам.

Владелец сервера назначает модератора из существующих аккаунтов локально. В SQLite игровой базы выполните команду, подставив имя проверенного игрока в параметр. Для снятия роли задайте 0.

```sql
UPDATE accounts SET chat_moderator = 1 WHERE name = :account_name;
```

Подписи в командах и чате, приглашения, жалобы и сообщения об ошибках доступны на русском и английском. Названия команд, имена и тексты сообщений отображаются как введены игроками.
