# Команды и приглашения

Раздел «Команды» открывается из профиля. Игрок с аккаунтом создаёт команду и приглашает знакомого по имени аккаунта. Создатель видит состав и ожидающие приглашения. Адресат может принять или отклонить приглашение. После принятия состав доступен обоим игрокам, в том числе после входа на другом устройстве. Список обновляется автоматически при открытом разделе.

В SQLite одному игроку соответствует одно место в команде. Повтор приглашения не создаёт вторую запись и сохраняет уже принятое членство. Посторонний аккаунт не видит команду и не может принять приглашение по чужому идентификатору.

Следующие шаги — управление нежелательными приглашениями и общение. Для публичного чата планируются отключение сообщений, блокировка автора и обращение к модератору.
