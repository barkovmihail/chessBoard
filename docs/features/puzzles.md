# Шахматные задачи

**Доступно в веб-версии.** Раздел выбирает случайную задачу из локального каталога. Игрок видит рейтинг, доску со своей стороны и может запросить подсказку. Можно выбрать мат в один ход, мат в два хода, вилку, связку или эндшпиль. «Следующая задача» сохраняет выбранную тему, «Все темы» возвращает общий каталог. Сервер отдаёт одну запись на запрос. Первый ход в поле Moves делает соперник до показа доски, решение начинается со второго полухода. Засчитывается решение из каталога или другой ход, сразу ставящий мат. Можно повторить позицию либо загрузить следующую задачу.

## Каталог

Источник — открытая база Lichess, лицензия CC0. В локальном снимке от 9 ноября 2026 года 6 193 530 задач. Сохранены исходный FEN, последовательность UCI, рейтинг, отклонение рейтинга, популярность, число решений, темы, ссылка на партию, дебютные метки и дата ежедневной задачи при наличии. [Лицензия, формат и загрузка](https://database.lichess.org/#puzzles)

Каталог занимает около 1,2 ГиБ в SQLite. Отдельный файл позволяет обновить задачи без перезаписи пользовательских партий. Обычный запуск читает его из каталога игровой базы. Переменная CHESSBOARD_PUZZLES_DB задаёт другой путь. Большой файл хранится локально, в Git входят импортер и описание его запуска.

## Воспроизведение и обновление

Из корня проекта, Python 3.12 или новее:

```sh
.venv/bin/python -m pip install -r backend/requirements-import.txt
curl -fL https://database.lichess.org/lichess_db_puzzle.csv.zst -o /tmp/lichess_db_puzzle.csv.zst
.venv/bin/python -m backend.import_puzzles /tmp/lichess_db_puzzle.csv.zst --database puzzles.sqlite3
```

Импортер собирает файл рядом с целевым, проверяет уникальность идентификаторов и целостность SQLite, затем заменяет каталог. На время обновления нужно место для архива и новой копии. После импорта сверить количество строк с публикацией Lichess.

**Приёмка.** GET /api/puzzles/random возвращает позицию, линию, тему и рейтинг. В браузере неправильный ход оставляет позицию прежней, правильный продвигает решение, а после последнего появляется «Задача решена». При отсутствии базы интерфейс предлагает повторить загрузку. Параметр theme выбирает точную метку каталога. Для пустой подборки сервер возвращает 404, и игрок может сменить тему. «История попыток» показывает дату первого хода, задачу, число ошибок и результат. Просмотр позиции и подсказка сами по себе не создают запись. Попытка начинается с первого ввода хода, включая ошибочный, а «Начать заново» начинает отдельную попытку со следующим ходом. Гость видит свою историю в этом браузере, после регистрации история доступна по аккаунту. Записи хранятся в игровой SQLite отдельно от обновляемого каталога. [Импорт](../../backend/import_puzzles.py) · [Выборка](../../backend/puzzles.py) · [Тренажёр](../../src/features/training/Trainer.tsx)

Проверка через мобильное окно Chrome входит в [сквозной сценарий тренажёров](../../backend/tests/browser_training.py).

Выбор языка в меню профиля переводит темы, подсказки, объяснение ошибочного хода и историю. Смена языка во время решения сохраняет текущую задачу и число ошибок в попытке.
