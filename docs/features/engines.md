# Игра с компьютером и анализ

**Статус:** запланировано (P2).

## Порядок подключения движков (P2)

1. **Leela Chess Zero (Lc0).** Для игры с компьютером сервер запускает Lc0 с выбранной сетью весов и передаёт позицию по UCI. Ограничить время поиска на ход. Проверка готовности — после e2–e4 бот отвечает легальным ходом через существующий сервис партии, а после перезагрузки видны оба полухода. [Настройка Lc0 и выбор сети](https://lczero.org/play/quickstart/)
2. **Stockfish.** После приёмки Lc0 добавить Stockfish как второй вариант в том же интерфейсе. Сохранять выбранный движок с партией. Проверка готовности — сыграть по партии с каждым движком, восстановить обе из архива и увидеть правильное имя соперника. Для послематчевого анализа использовать выбранный движок с возможностью отменить расчёт при смене позиции.
