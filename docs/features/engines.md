# Игра с компьютером и анализ

**P2.** Доступна нерейтинговая партия белыми против Lc0 или Stockfish. Контроль времени общий для обоих игроков. После перезапуска сервер находит сохранённые партии, в которых очередь компьютера.

На macOS команда `brew install lc0` устанавливает движок и сеть. Сервер ищет `lc0` в PATH либо использует путь `CHESS_LC0`. Для другой сети укажите файл в `CHESS_LC0_WEIGHTS`. Используется CPU-бэкенд Eigen. Начальный и обычный уровни ограничивают поиск 4 и 32 узлами соответственно, бюджет поиска — до 0,8 секунды.

Stockfish устанавливается командой `brew install stockfish`. Путь к своему исполняемому файлу можно указать в `CHESS_STOCKFISH`. Для Stockfish два уровня соответствуют значениям Skill Level 0 и 8, время поиска — 0,8 секунды. Имя движка видно в текущей партии и в истории профиля.

## Порядок подключения движков (P2)

1. **Leela Chess Zero (Lc0).** Для игры с компьютером сервер запускает Lc0 с выбранной сетью весов и передаёт позицию по UCI. Ограничить время поиска на ход. Проверка готовности — после e2–e4 бот отвечает легальным ходом через существующий сервис партии, а после перезагрузки видны оба полухода. [Настройка Lc0 и выбор сети](https://lczero.org/play/quickstart/)
2. **Stockfish.** После приёмки Lc0 добавить Stockfish как второй вариант в том же интерфейсе. Сохранять выбранный движок с партией. Проверка готовности — сыграть по партии с каждым движком, восстановить обе из архива и увидеть правильное имя соперника. Для послематчевого анализа использовать выбранный движок с возможностью отменить расчёт при смене позиции.

## Просмотр завершённой партии

В записи партии кнопки перехода по ходам, экспорт PGN и оценка позиции доступны на русском и английском. При смене языка уже полученная оценка и линия продолжения сохраняются.

Участник открывает запись из истории, выбирает ход и нажимает «Оценить позицию». Для партии с компьютером изначально выбран соперник, для остальных — Lc0. Оценка дана за белых в пешках или числом ходов до мата. Рядом показано до восьми полуходов в SAN. Для уже завершившейся на доске позиции выводится результат. Смена хода или движка отменяет прежний расчёт. Кнопка «Остановить анализ» освобождает движок.

Сервер восстанавливает позицию по записи партии и проверяет участие игрока. Поиск занимает около секунды, общий срок запроса с ожиданием свободного места — десять секунд. Одновременно доступны два расчёта анализа отдельно от ходов компьютерных соперников.
