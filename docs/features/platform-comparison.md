# Куда развивать ChessBoard после первого веб-релиза

Срез на 11 ноября 2026 года. Для сравнения использованы публичные страницы платформ и их справка. Состояние ChessBoard сверено с реализацией, журналом приёмки и контрактом запущенного сервера. Очередь работ ведётся в [ROADMAP.md](../../ROADMAP.md).

## Последовательные результаты и приёмка

1. **Закрыть начатую работу по движкам.** Сначала прогнать матрицу на временной базе. Для каждого из двух движков и пяти уровней через обычный экран создать партию, сыграть e2–e4, проверить легальный ответ и подпись после обновления страницы. Открыть ранее сохранённые партии easy/normal. Затем обновить локальный сервер и сверить его контракт со сборкой.
2. **Выпустить испанский язык.** Первый принимаемый шаг — выбор Español в профиле, создание приглашения 5+3 и перезагрузка. Далее — партия, разбор, задачи и дебюты, затем остальные разделы, ошибки и уведомления. Сквозная проверка меняет язык посреди решения и сохраняет позицию. Перенос согласованных компонентов Radix проверять на тех же экранах с длинными подписями.
3. **Вернуть игрока к собственной ошибке в тактике.** Добавить в истории действие «Решить снова». После повторного входа открывается та же задача в исходной позиции. Новая попытка сохраняется отдельно, предыдущая статистика остаётся доступной. Проверить пустую историю и задачу, исчезнувшую при обновлении каталога. Это самостоятельная поставка на существующих данных.
4. **Перенести ключевой момент из макета в настоящую партию.** Первый шаг — повтор любого выбранного хода на копии позиции. Затем искать существенную потерю оценки для сыгравшей стороны с ограниченным бюджетом анализа и сохранять найденный полуход. Приёмка включает партию с известной тактической ошибкой за чёрных и партию без подходящего момента. После попытки можно открыть продолжение и вернуться к исходной записи.
5. **Ввести персональное повторение дебютов.** Сначала сохранять ошибку с главой, вариантом, позицией и стороной игрока. Затем показать «Повторить сегодня». После правильного ответа следующий интервал увеличивается, после ошибки позиция возвращается раньше. Проверить сохранение расписания после перезапуска и изменение авторской главы.
6. **Дать обратную связь по тренировкам.** В профиле показать за выбранный период число решённых задач, долю решений с первой попытки и темы с повторными ошибками. Из темы можно начать упражнение. Проверить расчёт на известной последовательности попыток и экран нового игрока без истории.

После этих поставок выбрать следующий эксперимент по использованию разделов. Для регулярных тренировок рассмотреть базовые эндшпили против движка. Для клубов, которым тесно в аренах, — швейцарские турниры. Для игроков, собирающих собственные варианты, — совместное редактирование глав. Эти направления требуют разного объёма контента и аудитории. Десктоп-сборка остаётся перспективой после подтверждения потребности в автономной работе.
