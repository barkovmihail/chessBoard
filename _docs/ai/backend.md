# Сервер на Python

Применяй эти правила при реализации сервера партии.

- Маршрут FastAPI разбирает запрос и сессию, сервис выполняет сценарий, домен проверяет шахматные правила, репозиторий читает и записывает данные. SQL и ORM-модели остаются внутри слоя данных. Между слоями передавай типизированные значения.
- Передавай репозиторий и часы сервису явно. Связывай реализации в точке запуска. Домен проверяй на позиции и заданном времени. Для сохраняемого момента указывай UTC, для длительностей выбирай одну явную единицу.
- Собирай настройки в одном типизированном объекте и проверяй их при запуске. Путь SQLite передавай зависимостью, чтобы в тесте можно было выбрать временный файл.
- Освобождай соединения контекстным менеджером. Ограничивай время ожидания внешних операций. При закрытии WebSocket заверши задачи этой подписки. Пропускай отмену корутины после освобождения ресурсов. Блокирующий ввод-вывод и анализ движком выноси из цикла обработки сетевых событий.
- Представляй ожидаемые игровые отказы типизированным исходом или доменным исключением. Преобразуй его в ответ на границе API. При преобразовании неожиданного исключения сохраняй исходную причину. В журнал помещай идентификаторы запроса и партии, версию и длительность операции. Поля для записи выбирай явно.
