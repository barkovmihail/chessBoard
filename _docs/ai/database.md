# SQLite и миграции

- Храни описание схемы в моделях SQLAlchemy. Изменение, которое затрагивает существующую базу, сопровождай миграцией Alembic. Проверь создаваемую схему и значения старых записей после миграции.
- Выполняй связанные запросы одной команды в одной транзакции. Принятый ход, новая версия, часы и подтверждение команды должны фиксироваться вместе. Проверяй ожидаемую версию непосредственно при записи. Рассылай события после фиксации.
- Уникальные ограничения защищают номер полухода в партии и идентификатор команды участника. Включай внешние ключи на каждом соединении. Значения запроса передавай связанными параметрами.
- Ограничивай время ожидания блокировки. Проверяй конфликтующие записи на независимых соединениях к одному временному файлу. Сетевые вызовы выполняй за пределами транзакции.
- Загружай только данные, нужные экрану. Историю партий читай страницами. При замедлении проверь число запросов и план SQLite до добавления индекса.
