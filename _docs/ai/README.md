# Инструкции для ИИ-ассистентов

| Когда открыть | Документ |
|---|---|
| Любое изменение кода, документации или рабочей копии | [Работа в репозитории](workflow.md) |
| Изменения React-компонентов, стилей и состояния | [Интерфейс](ui.md) |
| Работа с Python, конфигурацией и асинхронными операциями | [Сервер](backend.md) |
| Изменение запросов клиента, HTTP или WebSocket | [Контракты и ошибки](api.md) |
| Запись партий, конкурентные изменения и миграции | [Данные и SQLite](database.md) |
| Выбор проверок и подготовка тестовых данных | [Тестирование](testing.md) |

Правила адаптированы из каталога `tuareg/_docs/ai`. Текущий клиент находится в `src/`, команды определены в [package.json](../../package.json). Сервер и его тесты находятся в backend/. Порядок постановки и приёмки шага адаптирован из super-claude. Обновляй правило в его тематическом документе. [AGENTS.md](../../AGENTS.md) служит общей точкой входа, [CLAUDE.md](../../CLAUDE.md) подключает её для Claude Code.
