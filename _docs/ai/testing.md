# Проверки

| Изменение | Что проверить |
|---|---|
| Клиент | Из корня запусти `npm test` и `npm run build`. Первая команда запускает клиентские тесты из tests/, вторая выполняет проверку типов и собирает Vite-приложение. |
| Внешний вид и управление | Открой экран через `npm start`. Проверь положение фигур и подписей на узком и широком экране. Для интерактивного действия проверь доступные способы ввода. |
| Шахматные правила | Подай исходную позицию и ход, затем проверь результирующую позицию, очередь и исход. Для повторений используй историю ходов. |
| Запись партии | Проверь повтор команды и две команды к одной версии. После повторного открытия базы должны совпасть позиция, часы и число полуходов. |
| Миграция | Проверь создание чистой базы и обновление временной базы с ранее сохранённой партией. Прочитай её обычным методом приложения. |
| Сеть и часы | Проверь игру в двух независимых браузерных сессиях, потерю связи и возврат. Для гонки между ходом и падением флага передай управляемые часы. |

Выбирай дополнительные тесты по изменившемуся поведению. Описывай действия игрока и наблюдаемый результат. В отчёте различай пройденные автоматические проверки, ручную проверку и оставшиеся ограничения.

Для серверного набора из корня выполни `.venv/bin/python -m unittest discover -s backend/tests`. Для сквозной проверки партии после сборки используй `.venv/bin/python -m backend.tests.browser_game`. Подготовка браузера описана в [README](../../README.md).
