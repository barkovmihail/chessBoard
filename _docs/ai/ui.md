# Интерфейс на React и TypeScript

- Экран партии собирай в `src/pages/game`. Переиспользуемая доска получает позицию через параметры. Новый игровой сценарий, например выбор фигуры для превращения, размещай в соответствующей функции интерфейса. Извне обращайся к модулю через его публичный `index.ts`. Разрешённые направления зависимостей описаны в [архитектуре](../../ARCHITECTURE.md).
- Используй строгую типизацию и существующие типы `Square` и `BoardPiece`. Проверяй внешние данные при получении. Приведение типа в TypeScript само по себе не проверяет ответ сервера.
- Храни выбранную клетку и состояние диалога рядом с компонентом. Владельцем серверного снимка служит экран партии. Производные значения вычисляй из снимка. При смене партии снимай подписки, отменяй запросы и очищай локальный выбор.
- Размещай CSS-модуль рядом с компонентом. Выражай размеры клеток через сетку. Проверяй совместное положение фигур и подписей при изменении ширины и ориентации. Для интерактивных клеток предусмотри управление с клавиатуры, видимый фокус и доступное имя.
- В списках используй стабильные ключи, например координату клетки. Отсчёт часов обновляй в компоненте часов. Когда заметна задержка, измерь перерисовки и проверь результат оптимизации на том же сценарии.
